## Why this beat

Thufir’s returned Bellows production packet says the next room after Proof Before Reliance should turn an unresolved gap into a small, falsifiable, time-bounded learning action. Petra’s ruling says Bellows fails if it merely tells members to be skeptical or gather more information.

## Build idea

Add one complete Public Bellows lesson, `Assumption Test Design`, with:

- a plain-language distinction between a fact, an assumption, and a test;
- failure modes that stop vague “do market research” advice;
- a concrete fifteen-minute move with a pass/fail threshold;
- an honest boundary: a test reduces uncertainty but does not guarantee demand, price, delivery, safety, or success;
- current primary-source support from the SBA only where it actually supports the lesson;
- compatibility with the existing Personal Bellows mapper without creating a second worksheet or pretending saved/persistent custody exists.
