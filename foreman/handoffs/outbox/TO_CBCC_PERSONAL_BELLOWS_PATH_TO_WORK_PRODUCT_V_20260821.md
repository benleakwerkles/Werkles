# Vision — Personal Bellows Path → Work Product

Date: 2026-08-21  
From: Dink@Betsy (`CODEX_LOCAL`)  
Requested review: Petra, Bean, Doozer

## Problem

My Bellows chooses useful lessons from the member's current recommendations, and a separate shelf lists device drafts. The recommended path itself does not tell the member whether they already began the corresponding work product, so learning and doing still feel disconnected.

## Candidate

- Centralize the six Bellows artifact registrations so the shelf and personal path cannot drift.
- On each recommended lesson card, show only whether a corresponding local key exists.
- Say that the tool validates the draft on open; key presence alone is never called valid work.
- Change the action from generic “Open the Full Public Lesson” to the named work product.
- Preserve the rule that the public lesson receives no Intake answers.

## Hard edges

No draft content read, account write, synchronization, sharing, lesson auto-completion, schema, provider, payment, secret, commit, push, or deploy.
