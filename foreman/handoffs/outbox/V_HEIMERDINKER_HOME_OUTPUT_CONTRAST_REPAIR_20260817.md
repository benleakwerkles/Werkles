# Vision — Home output centerpiece contrast repair

Date: 2026-08-17
Foreman: Heimerdinker@Betsy
Environment: local Home only

## Operator-observed failure

The new `You bring` prompt reads like a test and is needlessly difficult:

- orange `You bring` is readable;
- the title renders black and clashes with the dark blue/purple field;
- the explanatory body renders light gray and requires leaning in;
- the site overuses one dark purple/blue instead of using a coherent range;
- fixing font size alone did not fix the rendered cascade.

## Direction

Repair the entire prompt/output centerpiece as one system:

1. Orange title + white body is the default candidate.
2. Use a lighter purple family or a materially lighter field; do not repeat the
   darkest site purple merely for brand consistency.
3. Prove final computed colors and contrast, not source-token intent.
4. Preserve hierarchy, mobile containment, focus, and the Intake/Proof actions.
5. Remove any language that sounds like a test or diagnosis.

## Hard edges

No new protagonist/image, provider, secret, spend, SQL, production mutation,
push, merge, or deploy. Personal reviews through existing tasks only; no
subagents or new environments.
