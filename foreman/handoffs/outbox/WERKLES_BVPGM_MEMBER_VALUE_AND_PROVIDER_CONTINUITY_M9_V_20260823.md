# Werkles BVPGM M9 Vision — Member Value and Provider Continuity

Checkpoint: make the ten-route member spine earn the next action while keeping
account custody, synthetic matching, provider readiness, and release claims
plain and honest.

Workstreams:

1. Member value: Intake, Recommendations, Workshop, Match Deck, Formation, and
   Bellows must create useful, revisitable work rather than quizzes or dead ends.
2. Human continuity: remove internal/testing language, explain unfamiliar terms
   in context, and preserve visual pauses across text-heavy surfaces.
3. Provider runway: Crucible and related member copy must name the benefit,
   evidence boundary, disposal boundary, and stopping condition without implying
   activation.
4. Release integrity: reseal the exact candidate only after regression and real
   CBCC review state are recorded honestly.

Hard edges: no provider call, credentials, secret entry, schema/RLS, production
data, spend, new environment, Codex subagent, foreground input, commit, push,
deploy, alias change, or simulated review.
