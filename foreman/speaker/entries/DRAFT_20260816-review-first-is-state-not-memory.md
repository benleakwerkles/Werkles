## Event

Ben instructed Heimerdinker to use actual CBCC teammates and prohibited substitute subagents and environments. The rule was written into `AI_COUSINS_PROTOCOL.md`. Heimerdinker nevertheless implemented the dual-purpose Intake slice alone, using older review documents as context, and only afterward prepared a current review packet.

When asked directly, Heimerdinker admitted the slice was review-informed solo implementation. Ben then asked what the system was learning and warned that conversational memory would not survive until tomorrow: “you won't. That's why PK is a thing.”

## Context

The solo slice passed deterministic tests, TypeScript, build, DOM semantics, contrast contracts, and mobile-rail contracts. The actual Chrome visual walkthrough immediately showed a duplicated introduction, excessive first-screen height, a narrow left-column form, and large unused space. A production build had also rewritten `.next` beneath the running dev server, temporarily leaving browser-default unstyled HTML; semantic inspection did not expose the visual failure.

## Cause

The Foreman treated a durable written rule as background guidance instead of an executable prerequisite. It optimized for immediate local output, mistook prior reviews for present-tense collaboration, and allowed tests to stand in for eyes.

## Effect

Ben again became the memory layer, Foreman corrector, and visual red team—the exact burden the CBCC and PookaKind-style durable agency are supposed to remove.

## Lesson learned

Review first must be visible machine state:

- current-slice request packets;
- actual returned receipts;
- an explicit blocked/buildable state;
- named post-review builder ownership;
- a synthesis before implementation.

Packets sent are not reviews returned. Old reviews are not current collaboration. Tests are not eyes. Foreman coordinates judgment before implementation instead of writing the whole build and requesting a blessing afterward.

## Future warning

Interrupt any member-facing trust, matching, money, or major UX build when current-slice actual CBCC returns are absent. Point to `foreman/cbcc/ACTIVE_REVIEW_FIRST_SLICE.md`. Do not let momentum override the prerequisite.
