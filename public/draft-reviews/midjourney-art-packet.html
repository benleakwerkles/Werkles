v3 — the one-second rule. The forge concept set (v2) failed red-team: blower cranks, hallmark punches, and quench troughs are objects nobody outside a Renaissance festival can name. New law: every icon must be an object a stranger names in one second. Match. Hammer. Coins. Glove. OPEN sign. The Werkles flavor lives in the style — violet, teal, gold hairlines — never in obscure objects. Prompts below are complete and paste-ready.

Step 1 — Make MJ actually respect a reference image

Getting ignored? It's almost always one of these two:

TrapFix
Image not assigned as Style ReferenceIn the web app, after your image appears under the prompt bar, hover the thumbnail and click the paperclip icon. No paperclip = MJ mostly ignores it for style.
Localhost URL in --srefAny 127.0.0.1 / localhost link only exists on this machine — MJ's servers can't fetch it and fail silently. Save the file, upload it into MJ. Never paste local links.

Then: add --sw 400 to the prompt (style weight — default is timid; push toward 800 if it still drifts), and always include a text prompt — a reference image alone won't run.

The palette swatch to upload

MJ can't read hex codes, but it can copy colors from an image. Right-click, save, upload to MJ, paperclip it.

Part 2 — Photography: killing the CGI verdict

The daughter test is the real test. Prompt directly against the sheen — --style raw ON for all photography.

Order is everything: scene first, style words second, --parameters dead last. Anything you type after --no gets eaten by the negative list — if your scene comes after it, MJ never sees the scene and you get a random person in a cluttered room. Never use semicolons; MJ doesn't understand them.
v3 fix — light and emptiness are the anti-AI moves. "Dawn," "evening," "documentary," and "film grain" all push MJ toward dark, cluttered frames — and dark-plus-busy is exactly where AI photos rot (shadows hide mushy detail, clutter multiplies fake objects). These prompts now demand bright daylight, clean backgrounds, and minimal props, and put dark, moody, dim, clutter on the negative list.
v3.1 fix — killing the doppelgängers. Same prompt = same people, same pose, forever. Three rules now baked into every prompt below: (1) --c 20 — the chaos parameter is MJ's variety dial, push to 35 if grids stay samey; (2) every prompt describes its people concretely (age, build, background) — undescribed humans all come back as the same catalog model; (3) every prompt has a different verb and camera angle — and half of them don't face the camera at all.
